What SASE actually means

Secure Access Service Edge: the WAN and the security stack, delivered from one cloud under one policy. Sites, users and cloud workloads connect to the nearest point of presence (PoP), and everything is inspected there.

The network half

SD-WAN

  • An edge at every site: a box, a virtual edge in the cloud, or an agent on a laptop
  • Any underlay: broadband, 5G, and MPLS while it lasts
  • Application-aware routing, QoS and loss mitigation
  • A provider backbone (middle mile) between PoPs
+
The security half

SSE (Security Service Edge)

  • SWG: web filtering, TLS inspection, anti-malware
  • CASB and DLP: SaaS control and data protection
  • ZTNA: access to one app at a time, not the network
  • FWaaS and IPS: for internet and site-to-site traffic
=
Together

SASE: one platform, one policy

  • The policy is written once and enforced in every PoP
  • The same rules for a branch, a remote user and a cloud VPC
  • Single-pass inspection, so no chain of boxes to size
  • One log for network and security events

Gartner named SASE in 2019, and the SSE label for the security half followed in 2021. Whether it comes from one vendor or two (SD-WAN from one, SSE from another), ask where the policy lives and how many consoles you will run.
