# SASE in Practice

Interactive companion to the TorNOG Fall Meetup talk *SASE in Practice: Lessons from the Field (and What AI Changes)*, November 12, 2026.

Step through a typical migration (legacy hub and spoke, remote users first, branches in waves, target state) and follow nine traffic flows (including a public cloud VPC) through each phase: how the packet gets there, which capabilities act on it, the legacy issues and how SASE fixes each one, and the pitfalls seen in real migrations.

Keys: `←` `→` phase, `1`–`9` or `↑` `↓` flow, `F` SASE fixes or migration pitfalls, `P` present (full screen), `T` theme. Links such as `#p2/branch-dc` open a specific phase and flow.

Vendor-neutral and simplified, for discussion. The network is fictional. Views are my own, not my employer's.

The whole site is a single file, `index.html`, with no build step or server.
